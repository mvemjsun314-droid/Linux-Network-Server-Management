# Server Configuration Files

This directory documents the configuration files associated with the Linux-Based Network Server Configuration and Management System.

## Services Covered

* **BIND DNS:** Domain name resolution and DNS records.
* **DHCP:** Automatic IP address assignment to network clients.
* **Apache:** Web server configuration and virtual hosting.
* **Mail Server:** Sendmail and Dovecot configuration.
* **FTP:** File transfer service configuration.
* **Linux User Management:** User accounts, groups, and file permissions.

## Configuration Evidence

Actual configuration files or sanitized configuration excerpts should be added here where available.

Configuration details must reflect the services actually configured and tested in the project.

## Security Note

This project was developed in a virtual lab environment. Legacy services and configurations should not be considered production-ready without appropriate security improvements.
