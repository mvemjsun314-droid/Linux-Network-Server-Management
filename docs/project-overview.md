# Project Overview

## Problem Statement

Organizations need reliable network services to support communication, web hosting, file sharing, and centralized administration.

This project explores how these services can be configured and tested in a simulated company network using Linux.

## Proposed Solution

A Red Hat Linux virtual machine was configured as the server, and a Windows machine was used as the client. Webmin was used to manage server services through a web-based administration interface.

## Main Components

* **DNS:** Maps configured domain names to IP addresses.
* **Apache:** Hosts websites for different departments.
* **DHCP:** Provides automatic IP configuration to clients.
* **FTP:** Demonstrates file transfer between machines.
* **Mail Services:** Demonstrates email communication using Sendmail, Dovecot, and SquirrelMail.
* **User Management:** Organizes users, groups, and file permissions.

## Learning Outcomes

The project provided practical exposure to Linux administration, networking fundamentals, server configuration, and troubleshooting.
